# 基本
## SiteId
作成したページの URL から分かる。以下の場合 123

```
https://～/items/123/index
```

> [!Caution] 注意
> SiteId は自動採番らしく、自分で任意の数字にできないっぽい

## 各項目
管理＞テーブル管理＞エディタ＞対象を選択＞詳細設定

# 選択肢
## マスタテーブルを選択肢に表示する
以下の形式をドロップダウンリストに書く（数字は SiteId）

```
[[123]] 
```

以下のような JSON 形式でも書けるが、comment は公式記法じゃない

```
[
  {
    "_comment": "資格マスタ",
    "SiteId": 123
  }
]
```

将来チェックが厳しくなったりしたらバグになる可能性がある

## フィルタリング
### 文字

項目：値でフィルタリング

```
[
  {
    "SiteId": 123,
    "View": {
      "ColumnFilterHash": {
        "ClassA": "有効"
      }
    }
  }
]
```

ただし、status とかでフィルタリングするとき

| コード | 状況   |
| --: | ---- |
| 100 | 未着手  |
| 150 | 準備   |
| 200 | 実施中  |
| 300 | レビュー |
| 900 | 完了   |
| 910 | 保留   |

こういう設定の場合コードの数字でフィルタリングする必要がある

### 数値
範囲を指定する
"NumA": "[\"100,\"]"　以上
"NumA": "[\",100\"]"　以下
"NumA": "[\"50,100\"]"　範囲


## 初期値
既定値に値を入れて、選択肢にブランクを挿入しないに✅が必要てｓｔ
